## Indexer, agent and app fixes — offers for a named loan stay off the book

A borrower can now post an offer for one named loan, which only that loan's obligation handover can consume. Accept and match refuse such an offer, so it is never borrow demand that a lender can fill.

The indexer records which loan such an offer names, from the event announcing it, in a new column (migration 0117). The book page, the market list, the nearest-opposite read and the offer counts leave these offers out, as they already leave out sale and offset vehicles. The offer record carries the loan as `takeoverLoanId`.

The app's order book leaves them out too. When it reads the book from the chain it asks each borrower offer whether it names a loan. If that read fails, the offer stays in, and the accept preview then gives the refusal by name: "This request is reserved for taking over a named loan, so it can't be accepted or matched." The creator's Open orders still list the offer, so it can be cancelled there. The activity feed labels the event "Takeover offer posted".

The loan page's handover card ("Hand this loan to another borrower") now lists only requests posted for that loan, and checks again on the chain before anything is approved that the picked request names this loan. An ordinary borrow request can no longer take over a loan, so it is no longer offered there, and the card's wording says a request must be posted for the loan.

Anyone who is not a party to an active loan can now post such a request from the loan's page ("Offer to take over this loan"). The form shows the debt, the current rate, the due date and the collateral, and takes a yearly rate, a term in whole days that ends by the due date, and at least the loan's collateral, which is locked in the requester's own vault. The request carries exactly the loan's principal, all or nothing, with the loan's assets, and expires at the last moment its term still fits, because after that the handover would refuse it. The term is never longer than the platform allows, and is short enough that the borrower has at least an hour to use the request after the platform's waiting period. A rate far from the average for its term is shown with that average and must be confirmed before posting, so the request is not refused for it. The receipt says the requester receives no money and takes on the debt only if the borrower uses the request. Loans secured by an NFT, rentals and loans with less than a day left are refused by name. The borrower's handover card now says to share the page link with the person taking over.
