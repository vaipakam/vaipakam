## Thread — The keeper closes out loans past their grace period (PR #<n>)

The keeper has a new pass, `graceDefault`, that calls the permissionless time-based default on loans whose grace period has ended. Until now only health-factor liquidations ran automatically, so a past-grace loan stayed open until the lender pressed the close-out button on its page. With the pass armed, a lender who never opens the app is closed out and only has to claim. The pass runs every five minutes and attempts one loan per run across all networks, because every attempt costs a quote round, a simulation and a send against a per-run request allowance the keeper's other duties share; it rotates, so a loan which cannot be closed does not hold up the rest, and a backlog of past-grace loans is worked through one run at a time. A loan that is also below the health-factor line is left to the health-factor liquidation to sell, except that this pass still makes the no-swap close a collapsed loan takes, which the liquidation cannot make without a route.

It follows the same rules as the lender's close-out card. It skips a loan whose lender position has an accepted sale, or whose sale state the chain does not establish, because closing it would strand the buyer's payment. For liquid collateral it sends a quoted swap route built by the same route builder the app uses. It previews the call and does not send a route that the chain shows would fall into the full-collateral fallback. Just before sending it checks, at one fresh block, that the sale state still allows the close and that the collateral amount still matches the quote. Every loan it passes over is logged with the reason. The sale check now lives in the shared library and is used by both the app and the keeper, so the two cannot drift.

The pass ships dark. It needs its own `GRACE_DEFAULT_ENABLED` secret on top of `KEEPER_ENABLED`, and arming it on the live Worker is a separate owner decision. A loan with no working swap venue still stays open, and the lender's grace-over banner still has to be corrected to say what actually happens (#2484). Closes #2483.
