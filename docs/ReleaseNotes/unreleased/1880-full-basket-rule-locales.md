## Three translations were still calling a rule an accident (#1880)

When a default happens over collateral the platform cannot price, the whole
basket goes to the lender and nothing comes back. That is what the platform
always does on that route — not how one default happened to turn out — and the
guides used to describe it the softer way, which could leave a borrower waiting
for a remainder that will never be recorded.

The English guides were corrected earlier. Three translations were not: the
German, Spanish and Hindi advanced guides still told readers it was an outcome
rather than a rule, and their own Basic-guide counterparts in the same three
languages had already been fixed — so within a single language the two pages
disagreed.

They now match, in each language's own already-corrected wording rather than a
fresh translation, so the two guides say the same thing to the same reader.

Worth noting how this was found, because a sweep would have missed it: rather
than searching for a phrase, every guide in every language was checked for what
it says about this one situation. Seven of the ten advanced guides were already
right, which is exactly the pattern that makes a phrase-search report success.
