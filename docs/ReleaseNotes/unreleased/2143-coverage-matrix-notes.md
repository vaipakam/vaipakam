## Thread — The coverage matrix becomes a matrix again (PR #<n>)

The connected app's verification coverage matrix had grown long-form narrative inside its table cells, one of them past 60,000 characters, which no renderer can show as a table. Each row now carries a sentence or two per cell, at most 600 characters, and the full record behind a row (how each rule was arrived at, what a driver refuses to claim, and the review history) moved verbatim into a new notes file, linked from the cell. The app's typecheck now refuses a cell over the cap, a link to a notes section that does not exist, and a notes section nothing links to, and a row with more cells than its table has columns (three rows had pipes inside code that split them, so their last columns never rendered; their full text is now in the notes), so the per-PR habit of appending to the matrix cannot regrow it (Closes #2143).

> Caveat: a cell that had to be cut mid-sentence ends in an ellipsis; its full text is in the linked notes section, unchanged.
