## Keeper — mirror day closes resume on chains still sending the B4 report (PR #<n>)

The day-report change in PR #2790 (#2620, #2621) moved fresh deploys to one report shape, and the keeper's day-close pass started quoting only that shape. The live testnets still run messengers and Diamonds deployed before that change, which send the older B4 report. From the release that shipped it, every mirror close on BNB Testnet and Arbitrum Sepolia was refused with "the messenger has no quote for the report closeDay sends", starting with reward day 4. Day 4 was closed by hand from the keeper wallet at 03:52 UTC on 2026-10-26, paying the B4 quote.

The keeper now asks a mirror's messenger for the one report shape first, then for the B4 report. A chain whose messenger quotes only B4 has its days closed, paying that quote, but only while its Diamond's reporter is read as sending B4: it has `closeDay` and `getInterestFrontiers` on one facet. B4 is the one older shape Base applies after it has finalized a day. If the reporter does not send B4, the day is held and reported as refused; if that read fails, the day is left for the next run. A messenger that quotes neither shape is reported as refusing. On a B4 chain the route to Base is the messenger's own configuration, not a rule the contract enforces, and the rotated-messenger alert now says so.

This is keeper-only compatibility for chains deployed before #2790. The contracts still carry one report shape. The path is removed at the all-waves fresh deploy, when no served chain runs a pre-#2790 messenger (#2866).
