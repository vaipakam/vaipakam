## Thread — keeper backstop for deliberately zeroed reward days (PR #<n>)

When a mirror chain deliberately zeroes a reward day, its users are owed compensation from Base, and a day that is never compensated is retired as a recorded loss once its window closes. Each step of that process is permissionless, but nothing called the steps on a schedule. A zeroed day could therefore sit unquoted and unfunded, or never be retired, until someone made the calls by hand. The keeper now has a zeroed-day duty on every mirror it serves. It runs every fifteen minutes and looks back sixty days by default. It ships switched off, behind its own arming flag.

For each zeroed day whose own interest close has run and whose pool stamp is installed, the keeper submits the covering reward entries in pages, in ascending order. Once both sides add up exactly to the day's recorded totals, it dispatches the quote toward Base and pays the lane fee. That fee is held to the duty's own ceiling, `REWARD_ZEROED_DAY_MAX_FEE_WEI`, so raising another duty's ceiling never raises this one. A day that is never compensated is lapsed once its frozen window has passed, even if no quote was sent. After a lapse the keeper goes on accumulating, so the recorded loss becomes exact rather than partial. A day that was compensated below its quote is short-lapsed past its deadline. Each lapse is announced to operators with the loss it recorded.

Accumulation is open to anyone, so a third party can move a side's cursor past entries it never submitted. Once that happens, only the administrator's reset frees the side. The keeper detects this case, raises an operator alert, and leaves the reset to the administrator. A provisional credit, a missing lapse clock, a paused protocol, a missing key, an unread value, or a Diamond that names another chain each stops the affected step, and the run's report says why. The fee-ceiling helper is now shared by every duty that pays a fee, with one variable per duty. Refs #2984.

> Caveat: ships disarmed. Arming it on any chain is a separate owner decision.
> Caveat: a quote already dispatched is not re-sent. If a dispatched quote never reaches Base, the day lapses at the end of its window.
> Caveat: the entry scan reads the chain's reward-entry list from the start on every run, up to the same bound as the close-out duty. A longer list is reported as not walked.
