# Release Notes — 2026-11-18

One change reached main on this day. The Terms of Service are published as
version 3, with a reworded software risk line. Version 2 stays readable, and
wallets are asked to accept the new version only once the owner configures it
on each network.

## Thread — Terms of Service version 3: the software risk line (PR #3738)

The Terms of Service are published as version 3. One sentence changed and
nothing else. The risk line about software, price feeds, tokens and networks
used to end "It is new technology." It now ends "These risks come with every
blockchain system." The owner chose this wording after comparing how other
large lending and exchange platforms state the same risk: a phrase about
newness goes stale as the platform ages, while removing the sentence with
nothing in its place would have weakened the disclosure.

Version 2 stays frozen and readable at its own address, as every published
version does, so an acceptance recorded against it still resolves to the
exact text that was accepted. The unversioned Terms address now serves
version 3. The connected app's key-risk list, shown with the Terms before a
first acceptance and on the Key risks page, carries the same new sentence.

Publishing on the website does not change what a wallet is asked to accept.
A version becomes the one a network asks for only when the owner configures
it there, and that step is separate and has not been taken by this change.

> Caveat: until version 3 is configured on a network, that network still asks for version 2, whose pinned text ends the line the old way, while the app's key-risk list already shows the new sentence.
